# LabOS · Scientific Macintosh

LabAssistant 的浅色视觉规格。层级由实体面板、直角边框和排版形成；彩色像素只用于品牌、类别与状态。工作区优先保证课程、任务和统计数据可快速扫描。

| 角色 | 颜色 | 用途 | 对典型面板 `#F7F5EE` 对比度 |
| --- | --- | --- | ---: |
| 正文 | `#23292B` | 主要内容 | 13.52:1 |
| 次要文字 | `#3F4B50` | 辅助内容 | 8.25:1 |
| 弱化文字 | `#586168` | 提示 | 5.79:1 |
| 强调文字 | `#236F87` | 导航、链接、图表 | 5.21:1 |
| 主按钮 | `#145267` | 白字操作按钮 | 白字 7.91:1 |
| 工作区桌面 | `#D8D5CA` | 像素点纹理 | — |
| 典型面板 | `#F7F5EE` | 页面卡片 | — |
| 面板边框 | `#66665F` | 1px 轮廓 | — |
| 成功 / 警告 / 危险 | `#18624E` / `#875716` / `#B84F44` | 状态 | 见 `theme.py` 可读色函数 |

圆角刻度为 2–4px；面板向右下偏移 2px 阴影并在顶部、左侧各有一道浅色高光。窗口横纹仅在工作区顶部出现。按钮使用凸起式边框，输入框使用凹入式边框和 2px 焦点框。表格、图表与 Markdown/文本输入保留现代密度。

状态统一使用方形色块：实心表示完成，空心表示未完成，斜纹表示处理中；今天使用方形日期徽标。统计页以独立方框显示月度读数，用 40 格方格仪表表示完成率（每格 2.5%），每日趋势用无渐变的直线和方形节点，每周累计用直角实色柱。数据标签、目标线及统计口径保留，避免复古外观影响阅读。

品牌标是经典 Macintosh 主机与实验烧瓶的像素图，原图 `assets/labos_icon_master.png`；`scripts/make_labos_icons.py` 生成应用和侧栏图标。小组件使用同一状态语义色；点击时隐藏宿主把 `labassistant-widget://today` 转发给主应用的 `labassistant://today`。
